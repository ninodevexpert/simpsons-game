# Instrucciones de este proyecto

Aplicación local React + Vite para explorar personajes de Los Simpson. Mantener la ejecución local; no usar Sites ni desplegar salvo petición explícita.

## Skills de alcance local

Antes de modificar la aplicación, consultar las skills relevantes de este repositorio:

- **springfield-design** — `.agents/skills/springfield-design/SKILL.md`: usar al crear, modificar o revisar interfaz, estilos, componentes, botones, tarjetas, modales, textos de interfaz o comportamiento responsive.
- **springfield-api** — `.agents/skills/springfield-api/SKILL.md`: usar al consultar o modificar datos, peticiones, personajes, paginación, imágenes, caché o estados de carga/error de The Simpsons API.
- Para tareas que mezclen interfaz y datos, aplicar ambas. No cargar las skills para tareas sin relación, como una operación exclusivamente Git.

Estas skills son locales a este proyecto. Las instrucciones explícitas del usuario prevalecen sobre sus convenciones. Si un cambio solicitado altera un patrón o el contrato conocido, actualizar la documentación afectada para evitar que quede obsoleta.

## Referencias de trabajo

- `src/main.jsx`: componentes y acceso a datos.
- `src/styles.css`: estilos y tokens visuales.
- `index.html`: fuentes y metadatos.
- `npm run dev`: servidor local.
- `npm run build`: comprobación de compilación tras cambios de aplicación. Para cambios solo de documentación, validar esa documentación sin recompilar innecesariamente.
